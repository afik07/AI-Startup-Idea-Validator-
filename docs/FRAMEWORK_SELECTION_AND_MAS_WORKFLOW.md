# Framework Selection & MAS Workflow Justification

## System Name: GammaVal™ AI Startup Idea Validator

### 1. Framework Justification: Custom Async MAS Pipeline vs Heavy Frameworks
For maximum execution speed, zero runtime overhead, and browser-native reactivity, GammaVal™ AI utilizes a lightweight, event-driven Multi-Agent Architecture built with native ES6 Modules, OpenRouter REST Gateways, and Tavily Search APIs rather than heavy Python frameworks (e.g., CrewAI or LangChain).

### 2. Multi-Agent Pipeline Sequence
1. **Market Opportunity Agent**: TAM, SAM, SOM calculation and CAGR projections.
2. **Customer Segmentation Agent**: ICP summary, buyer persona breakdown, WTP rating.
3. **Competitor Discovery Agent**: Live web search via Tavily API for direct rivals and pricing tiers.
4. **Strategic Comparison Agent**: Us vs Rivals matrix, market gaps, UVP, and 0-100 Validation Scorecard.
5. **SWOT & Risk Analysis Agent**: 2x2 SWOT grid and Risk Index breakdown.
6. **MVP MoSCoW Feature Agent**: Must, Should, Could, Won't Have prioritization.
7. **Go-To-Market Strategy Agent**: Positioning, acquisition channels, and 90-day launch roadmap.
8. **Conversational AI Advisor**: Ingests full KB for follow-up strategy Q&A.
